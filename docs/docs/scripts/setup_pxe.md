# iPXE Boot Setup Script

The iPXE boot setup script (`setup-ipxe.sh`) configures iPXE boot server for physical machines. **Note:** This implementation uses iPXE (not traditional PXE with pxelinux.0) for Windows 11 UEFI Secure Boot support.

## Overview

iPXE (open-source boot firmware) is an enhanced version of PXE that supports HTTP boot, which is required for Windows 11 UEFI Secure Boot. This setup script:

- Installs and configures TFTP server
- Configures dnsmasq for DHCP/DNS with iPXE support
- Sets up iPXE boot files for Windows 11 UEFI Secure Boot
- Configures iPXE boot menu and HTTP boot script endpoint
- Configures vendor class matching for different architectures (UEFI64, UEFI32, BC_EFI)
- Sets up iSCSI targets for disk image booting

## PXE vs iPXE

**Traditional PXE:**
- Uses `pxelinux.0` bootloader
- Only supports TFTP protocol
- Limited to legacy BIOS systems
- Not compatible with Windows 11 UEFI Secure Boot

**iPXE (used in ggnet2):**
- Uses `ipxe.efi` bootloader (UEFI)
- Supports HTTP, TFTP, and other protocols
- Compatible with UEFI and Windows 11 UEFI Secure Boot
- Supports HTTP boot script endpoint for dynamic configuration

## Usage

```bash
# Run iPXE setup script
sudo bash scripts/setup-ipxe.sh

# Or with custom configuration
TFTP_ROOT="/var/lib/tftp" bash scripts/setup-ipxe.sh
```

## Script Structure

**setup-ipxe.sh:**
```bash
#!/bin/bash

set -e

# Configuration
TFTP_ROOT="${TFTP_ROOT:-/var/lib/tftp}"
# Note: iPXE doesn't use pxelinux.cfg directory - configuration is via HTTP boot script
DHCP_RANGE_START="${DHCP_RANGE_START:-192.168.1.100}"
DHCP_RANGE_END="${DHCP_RANGE_END:-192.168.1.200}"
DHCP_SUBNET="${DHCP_SUBNET:-192.168.1.0}"
DHCP_NETMASK="${DHCP_NETMASK:-255.255.255.0}"
DHCP_GATEWAY="${DHCP_GATEWAY:-192.168.1.1}"

# Functions
print_info() {
    echo "[INFO] $1"
}

print_error() {
    echo "[ERROR] $1" >&2
}

# Install packages
install_packages() {
    print_info "Installing PXE boot packages..."
    
    apt-get update
    apt-get install -y \
        tftpd-hpa \
        syslinux \
        syslinux-common \
        dnsmasq \
        targetcli-fb \
        python3-rtslib-fb
}

# Setup TFTP server
setup_tftp() {
    print_info "Setting up TFTP server..."
    
    # Create TFTP root directory
    mkdir -p "$TFTP_ROOT"
    # Note: iPXE doesn't use pxelinux.cfg directory - configuration is via HTTP boot script
    mkdir -p "$TFTP_ROOT/i386-efi"
    
    # Copy iPXE boot files for UEFI (Windows 11 Secure Boot)
    # Download or copy iPXE files to TFTP root
    # iPXE files should be placed in /var/lib/tftp/ directory
    # Required files:
    #   - ipxe.efi (main UEFI bootloader for Windows 11)
    #   - ipxe_202006.efi, ipxe_202102.efi (alternative versions)
    #   - snp.efi, snponly.efi (SNP driver for UEFI network)
    
    # Create iPXE directory structure
    mkdir -p "$TFTP_ROOT/i386-efi"
    
    # Note: iPXE files should be downloaded from official sources
    # or copied from ggrock package
    # Place iPXE files in appropriate locations:
    #   - UEFI64: ipxe.efi (main bootloader)
    #   - UEFI32: i386-efi/ipxe.efi
    #   - SNP driver: snp.efi, snponly.efi
    
    print_info "iPXE files should be placed in $TFTP_ROOT/"
    print_info "Required files: ipxe.efi, i386-efi/ipxe.efi, snp.efi, snponly.efi"
    
    # Configure TFTP server
    cat > /etc/default/tftpd-hpa <<EOF
TFTP_USERNAME="tftp"
TFTP_DIRECTORY="$TFTP_ROOT"
TFTP_ADDRESS="0.0.0.0:69"
TFTP_OPTIONS="--secure"
EOF
    
    # Set permissions
    chown -R tftp:tftp "$TFTP_ROOT"
    chmod -R 755 "$TFTP_ROOT"
    
    # Enable and start TFTP server
    systemctl enable tftpd-hpa
    systemctl restart tftpd-hpa
    
    print_info "TFTP server configured"
}

# Setup dnsmasq
setup_dnsmasq() {
    print_info "Setting up dnsmasq..."
    
    # Backup existing config
    if [ -f /etc/dnsmasq.conf ]; then
        cp /etc/dnsmasq.conf /etc/dnsmasq.conf.backup
    fi
    
    # Get server IP address
    SERVER_IP=$(hostname -I | awk '{print $1}')
    
    # Configure dnsmasq with iPXE support for Windows 11 UEFI Secure Boot
    cat > /etc/dnsmasq.conf <<EOF
# This file has been generated by ggnet2 PXE setup script
# Config based on info from: https://wiki.fogproject.org/wiki/index.php?title=ProxyDHCP_with_dnsmasq

# Don't function as a DNS server:
port=0

# Log lots of extra information about DHCP transactions.
log-dhcp

# Set the root directory for files available via TFTP.
enable-tftp
tftp-root=${TFTP_ROOT}
# tftp-secure

# The boot filename, Server name, Server Ip Address
# LEGACY_NBP is for legacy BIOS boot (if needed)
# dhcp-boot=LEGACY_NBP,,${SERVER_IP}

# Disable re-use of the DHCP servername and filename fields as extra
# option space. That's to avoid confusing some old or broken DHCP clients.
dhcp-no-override

# Inspect the vendor class string and match the text to set the tag
dhcp-vendorclass=BIOS,PXEClient:Arch:00000
dhcp-vendorclass=UEFI32,PXEClient:Arch:00006
dhcp-vendorclass=UEFI,PXEClient:Arch:00007
dhcp-vendorclass=UEFI64,PXEClient:Arch:00009

# Set the boot file name based on the matching tag from the vendor class (above)
# UEFI64: Windows 11 UEFI Secure Boot (main bootloader)
dhcp-boot=net:UEFI64,ipxe.efi,,${SERVER_IP}
# UEFI: Generic UEFI boot
dhcp-boot=net:UEFI,ipxe.efi,,${SERVER_IP}
# UEFI32: 32-bit UEFI boot
dhcp-boot=net:UEFI32,i386-efi/ipxe.efi,,${SERVER_IP}
# BC_EFI: Boot Configuration EFI (UEFI PXE-BC)
dhcp-boot=net:BC_EFI,ipxe.efi,,${SERVER_IP}

# iPXE chainloading: Match iPXE clients and chainload to HTTP boot script
dhcp-match=ipxe,175
dhcp-boot=net:ipxe,http://${SERVER_IP}/boot/script?mac=\${netX/mac}&ip=\${netX/ip}&if=\${ifname},,${SERVER_IP}

# PXE menu. The first part is the text displayed to the user. The second is the timeout, in seconds.
pxe-prompt="Booting ggnet2 Client", 1

# The known types are x86PC, PC98, IA64_EFI, Alpha, Arc_x86,
# Intel_Lean_Client, IA32_EFI, BC_EFI, Xscale_EFI and X86-64_EFI
# This option is first and will be the default if there is no input from the user.
# iPXE-based boot services (HTTP boot)
pxe-service=net:ipxe,X86PC, "Boot to ggnet2", http://${SERVER_IP}/boot/script?mac=\${netX/mac}&ip=\${netX/ip}&if=\${ifname}
pxe-service=net:ipxe,X86-64_EFI, "Boot to ggnet2 UEFI", http://${SERVER_IP}/boot/script?mac=\${netX/mac}&ip=\${netX/ip}&if=\${ifname}
pxe-service=net:ipxe,BC_EFI, "Boot to ggnet2 UEFI PXE-BC", http://${SERVER_IP}/boot/script?mac=\${netX/mac}&ip=\${netX/ip}&if=\${ifname}
# Legacy BIOS boot (if needed)
# pxe-service=X86PC, "Boot to ggnet2", LEGACY_NBP
# UEFI boot (if iPXE not available)
pxe-service=X86-64_EFI, "Boot to ggnet2 UEFI", ipxe.efi
pxe-service=BC_EFI, "Boot to ggnet2 UEFI PXE-BC", ipxe.efi

# DHCP range (proxy mode)
dhcp-range=${SERVER_IP},proxy
EOF
    
    # Enable and start dnsmasq
    systemctl enable dnsmasq
    systemctl restart dnsmasq
    
    print_info "dnsmasq configured"
}

# Note: iPXE doesn't use static menu files like traditional PXE
# Menu configuration is handled via HTTP boot script endpoint
# This function is kept for compatibility but not used with iPXE
setup_pxe_menu() {
    print_info "iPXE uses HTTP boot script endpoint - no static menu needed"
    print_info "Menu configuration is handled dynamically via /boot/script endpoint"
}

# Setup iSCSI targets
setup_iscsi() {
    print_info "Setting up iSCSI targets..."
    
    # Enable iSCSI target service
    systemctl enable target
    systemctl start target
    
    print_info "iSCSI targets configured"
}

# Main
main() {
    print_info "Starting PXE boot setup..."
    
    # Check if running as root
    if [ "$EUID" -ne 0 ]; then
        print_error "Please run as root (use sudo)"
        exit 1
    fi
    
    # Install packages
    install_packages
    
    # Setup TFTP server
    setup_tftp
    
    # Setup dnsmasq
    setup_dnsmasq
    
    # Setup PXE menu
    setup_pxe_menu
    
    # Setup iSCSI targets
    setup_iscsi
    
    print_info "PXE boot setup complete!"
}

main "$@"
```

## Configuration

### TFTP Configuration

**TFTP Root:**
- Default: `/var/lib/tftp` (or `/tftpboot` if using legacy setup)
- Can be customized via `TFTP_ROOT` environment variable

**iPXE Files for Windows 11 UEFI Secure Boot:**
- `ipxe.efi`: Main UEFI bootloader for Windows 11 (UEFI64)
- `i386-efi/ipxe.efi`: 32-bit UEFI bootloader (UEFI32)
- `ipxe_202006.efi`, `ipxe_202102.efi`: Alternative iPXE versions (if needed)
- `snp.efi`, `snponly.efi`: SNP driver for UEFI network (optional)

**File Locations:**
- UEFI64: `/var/lib/tftp/ipxe.efi`
- UEFI32: `/var/lib/tftp/i386-efi/ipxe.efi`
- SNP Driver: `/var/lib/tftp/snp.efi`, `/var/lib/tftp/snponly.efi`

**Note:** iPXE files should be downloaded from official iPXE sources or copied from ggrock package.

### DHCP Configuration

**DHCP Range:**
- Start: `192.168.1.100` (configurable)
- End: `192.168.1.200` (configurable)
- Subnet: `192.168.1.0/24` (configurable)

**DHCP Options:**
- Router (Gateway): `192.168.1.1`
- DNS Server: `192.168.1.1`
- Netmask: `255.255.255.0`

### dnsmasq Configuration for iPXE

**Vendor Class Matching:**
- `BIOS`: Legacy BIOS boot (PXEClient:Arch:00000)
- `UEFI32`: 32-bit UEFI boot (PXEClient:Arch:00006)
- `UEFI`: Generic UEFI boot (PXEClient:Arch:00007)
- `UEFI64`: 64-bit UEFI boot for Windows 11 (PXEClient:Arch:00009)

**Boot File Configuration:**
- **UEFI64**: `ipxe.efi` (Windows 11 UEFI Secure Boot)
- **UEFI**: `ipxe.efi` (Generic UEFI)
- **UEFI32**: `i386-efi/ipxe.efi` (32-bit UEFI)
- **BC_EFI**: `ipxe.efi` (Boot Configuration EFI)

**iPXE Chainloading:**
- Detects iPXE clients (vendor class 175)
- Chainloads to HTTP boot script: `http://SERVER_IP/boot/script?mac=...&ip=...&if=...`
- Uses HTTP boot for Windows 11 UEFI Secure Boot support

**HTTP Boot Script Endpoint:**
- URL: `http://SERVER_IP/boot/script?mac={mac}&ip={ip}&if={ifname}`
- Parameters:
  - `mac`: MAC address of client
  - `ip`: IP address of client
  - `if`: Interface name
- Returns: iPXE boot script for client configuration

### iPXE Boot Menu Configuration

**Default Menu:**
- Boot to ggnet2 (X86PC - Legacy BIOS via iPXE)
- Boot to ggnet2 UEFI (X86-64_EFI - Windows 11 via iPXE)
- Boot to ggnet2 UEFI PXE-BC (BC_EFI via iPXE)

**Menu Timeout:**
- Default: 1 second
- Configurable via `pxe-prompt` directive

**Note:** All boot options use iPXE bootloader, which then chainloads to HTTP boot script endpoint for dynamic configuration.

### HTTP Boot Script Endpoint

**Backend API Endpoint:**
- URL: `/boot/script?mac={mac}&ip={ip}&if={ifname}`
- Method: `GET`
- Returns: iPXE boot script

**iPXE Boot Script Format:**
```ipxe
#!ipxe
dhcp
set base-url http://SERVER_IP
sanboot --no-describe iscsi:${SERVER_IP}:::1:iqn.ggnet2.client.${mac}
```

**Script Parameters:**
- `mac`: MAC address of client (from query parameter)
- `ip`: IP address of client (from query parameter)
- `if`: Interface name (from query parameter)

**Script Generation:**
- Backend API generates iPXE script dynamically based on client MAC address
- Script includes iSCSI target configuration
- Script includes client-specific settings

**Example Request:**
```bash
curl "http://localhost/boot/script?mac=00:11:22:33:44:55&ip=192.168.1.100&if=eth0"
```

**Example Response:**
```ipxe
#!ipxe
dhcp
set base-url http://192.168.1.10
sanboot --no-describe iscsi:192.168.1.10:::1:iqn.ggnet2.client.00-11-22-33-44-55
```

### Secure Boot Certificate Setup

**For Windows 11 UEFI Secure Boot:**
- iPXE must be signed with a certificate trusted by UEFI Secure Boot
- Certificate should be installed in UEFI firmware
- Or use Microsoft-signed iPXE binaries

**Certificate Installation:**
- Add certificate to UEFI firmware: `MOKManager` or `Secure Boot` settings
- Or use pre-signed iPXE binaries from trusted sources

**Note:** Secure Boot certificate setup is client-side configuration and should be done during client setup.

## Troubleshooting

### TFTP Server Not Working

**Check TFTP Server:**
```bash
# Check TFTP server status
systemctl status tftpd-hpa

# Check TFTP logs
journalctl -u tftpd-hpa -f

# Check firewall
ufw status
```

### DHCP Not Working

**Check dnsmasq:**
```bash
# Check dnsmasq status
systemctl status dnsmasq

# Check dnsmasq logs
journalctl -u dnsmasq -f

# Check dnsmasq configuration
dnsmasq --test
```

### iPXE Boot Fails

**Check iPXE Files:**
```bash
# Check iPXE boot files
ls -la "$TFTP_ROOT"

# Check iPXE bootloader files
ls -la "$TFTP_ROOT/ipxe.efi"
ls -la "$TFTP_ROOT/i386-efi/ipxe.efi"

# Test iPXE boot file download
tftp localhost
get ipxe.efi

# Check HTTP boot script endpoint
curl "http://localhost/boot/script?mac=00:11:22:33:44:55&ip=192.168.1.100&if=eth0"
```

## Development Notes

- TFTP server uses `tftpd-hpa` package
- dnsmasq handles both DHCP and DNS with iPXE support
- iPXE boot files should be downloaded from official iPXE sources or copied from ggrock package
- iPXE uses HTTP boot script endpoint instead of static config files (like traditional PXE)
- All boot scenarios (BIOS, UEFI32, UEFI64) use iPXE bootloader
- iSCSI targets are configured via targetcli
- Configuration files are backed up before modification
